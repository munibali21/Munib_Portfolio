# Munib Ali — BI Developer Portfolio

A responsive GitHub Pages portfolio for showcasing Power BI, SQL, Python and Excel projects.

## Folder structure

- `index.html` — homepage
- `projects/` — individual project case-study pages
- `images/` — dashboard screenshots
- `css/style.css` — site styling
- `js/script.js` — mobile navigation
- `resume/` — place your PDF resume here

## Add your screenshots

Replace the placeholder areas on the project pages with images such as:

```html
<img src="../images/hr/OV.PNG" alt="HR Report Overview">
```

Keep the image filename and capitalization exactly the same as the real file.

## GitHub Pages

Upload this folder to a GitHub repository and enable GitHub Pages from:

Settings → Pages → Deploy from branch → main → /root
